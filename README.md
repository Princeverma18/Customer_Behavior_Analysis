# 👨‍💻 Customer Behavior Data Analysis Project

## 📌 Overview

This project is an end-to-end data analytics case study where I analyzed customer shopping behavior to uncover meaningful business insights.

The main objective was to simulate a real-world data analyst workflow — starting from raw data cleaning to building an interactive dashboard and generating actionable insights.


## 🎯 Objective

The goal of this project is to understand customer behavior and answer key business questions such as:

Q1. Who are the most valuable customers?

Q2. What factors influence customer purchases?

Q3. How can businesses improve customer retention?

Q4. What trends can help in decision-making?

## 🛠️ Tools & Technologies Used
🐍 Python (Pandas, NumPy, Matplotlib, Seaborn)
🗄️ SQL (MySQL / PostgreSQL)
📊 Power BI
📓 Jupyter Notebook


# 🔄 Project Workflow

## 1️⃣ Data Cleaning & Exploration (Python)
* Handled missing values
* Renamed columns for better readability
* Performed exploratory data analysis (EDA)
* Identified patterns and anomalies

  
## 2️⃣ Data Analysis using SQL

* Loaded cleaned data into SQL database
* Wrote queries to answer business questions
* Performed customer segmentation
* Analyzed purchasing behavior

  
## 3️⃣ Dashboard Creation (Power BI)
* Built an interactive dashboard
* Visualized key metrics like:
* Total Revenue
* Customer Segments
* Purchase Trends
* Created filters for dynamic analysis

  
## 4️⃣ Insights & Reporting
* Derived meaningful insights from data
* Provided business recommendations
* Created a presentation for stakeholders

  
## 📊 Key Insights
* High-value customers contribute a major portion of revenue
* Certain product categories drive more engagement
* Customer segmentation helps in targeted marketing
* Purchase patterns vary based on demographics
